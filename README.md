# JMK Game Space (com.jmkgame.space)

Booster game ala RedMagic Game Space untuk Android 8+ (target API 34).

- Build: push ke `main` -> tab Actions -> artifact `GameSpace-release-apk`.
- Smart Sidebar: aktifkan di tab BOOST, kasih izin Overlay + Usage Access, add game di tab GAMES.
- Tab STYLE: warna tema, background dari galeri, icon custom (lewat shortcut home).
- FPS monitor: butuh Shizuku atau root (Android nggak ngizinin app biasa baca FPS app lain).
- Log app: tab LOGS (file files/gamespace.log).
- Keystore `app/gamespace.jks` dipakai supaya tiap build punya signature sama.
